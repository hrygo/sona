# 声音工坊 UX 分支闭环检查

## 范围与证据层级

基于 Sona PR #15 的 `3aedafc` 进行增量审计。目标是把声音工坊的每个已列举分叉接回
可继续操作的路径，而不是只证明单个 API 返回成功。具体流程见[引导式创建架构](voice-studio-guided-creation.md)。

分三层，不互相冒充：

1. **失败回归**：原基线上先复现 7 项失败，覆盖旧试听状态残留、启用回调、删除、静音等待、
   确定失败后编辑与成功后返回编辑。修复后保留测试，不放宽生产确认语义。
2. **串联浏览器检查**：实际 React App、浏览器音频播放和原生 MediaRecorder、实际 Sona HTTP
   代理与 WebSocket 控制处理器；浏览器传输通过显式测试适配器送到本机服务，外部 SpeechRail
   引擎和音源为夹具。不是只有组件 mock，也不是直接调用真实 MLX。
3. **目标机验收**：真实麦克风、Safari/WebKit、SpeechRail Quality 模型、声纹、噪声、听感、
   首包与内存。本轮没有执行这一层，不能由软件绿灯推断其通过。

测试适配器是明确的测试边界：无浏览器网络导航、无解除企业浏览器策略、无真实麦克风访问。
音源为 AudioContext 生成的测试信号，经过浏览器原生 MediaRecorder；这可以检查容器、
原始字节、暂停与释放的程序行为，不能验证真人录音和声学质量。

## 本轮修复的不变量

- **确认才算启用**：UI → modal → AssistantPanel → command socket 都保留 Promise。
  `set_voice` 返回的状态必须包含目标 voice；ACK 不匹配仍是失败，不能先提示成功。
- **没有旁路**：主界面的 clone/generated 下拉选择进入检查页；只有本次完整输出证据与
  试听成功后才提供启用。旧系统/instruction 音色保留原有使用方式。
- **证据不能过期复用**：再次试听、复测或取消撤销旧确认；缺少/畸形失败码列表不当作空列表。
- **删除也是异步流程**：仅一个确认框；失败保持打开、允许重试。删除当前音色先确认默认声音，
  切换失败不发 DELETE。切换成功而删除失败时如实保留“当前默认、旧资产尚在”的状态。
- **不确定不是失败或回滚**：停止客户端等待不证明服务端没有保存。设计及录音均保存本次请求身份，
  先查结果或按同一身份重试；另起尝试需显式确认，旧资产不静默覆盖或删除。
- **录音不变更源数据**：重试保留原始 Blob、实际 MIME、明确 ID 和准确参考文本；上传克隆的
  `Idempotency-Key` 经有界 ASCII 校验后透传，浏览器不构造 multipart boundary。
  SpeechRail 缓存不保证跨重启幂等，不能宣称 exactly-once。
- **资源生命周期有始有终**：声音操作等待助手静音确认；等待中关闭先等静音结束再恢复。
  麦克风权限晚到时停止返回的轨道；空录音、录音器错误、设备中断均返回可重新录制状态。
- **不丢草稿**：切换页签、返回编辑和能力刷新保留描述；未提交录音、修改描述或不确定注册
  关闭前提示。确认关闭只丢弃本地草稿，不删除已保存音色。
- **模态独占交互**：全局模式/搜索/麦克风快捷键不穿透；嵌套删除框的 Escape 不关闭父工坊。
  刷新失败保留旧列表，提示错误和重试，不把错误伪装为空档案库。

## 浏览器分支矩阵

每组可包含多个连续分叉。完整断言在 `scripts/voice_studio_e2e_cases.py`，运行结果逐组写入
`results.json`。下面 30 组代表本轮声明的检查范围，不声称穷举了浏览器/网络/设备的无限组合。

| ID | 分叉 | 闭环/关键断言 |
| --- | --- | --- |
| D01 | 提示词完整成功路径 | 示例→注册→参考/输出分离→18 段→实际试听→等待目标状态 ACK→关闭恢复麦克风 |
| D02 | 示例与修改 | 六卡片、修改覆盖取消/确认、名称保留、切换保留草稿、非法参考文本不提交 |
| D03 | 草稿试听失败/重试/取消 | 失败保持编辑，成功播放实际音频，取消不创建资产 |
| D04 | 注册确定被拒绝 | ASR 不可用时恢复可编辑，不把明确未发布误当永久结果不确定 |
| D05 | 已保存但回包丢失 | 查询档案库失败后重试找回，同 ID，不额外创建 |
| D06 | 畸形成功包络 | 拒绝假成功，进入保存结果核对而非静默创建下一音色 |
| D07 | 取消注册/同 ID 重试 | 允许晚到保存，重试相同 ID/正文，409 后可核对找回 |
| D08 | 已保存后回编辑 | 原描述保留、新尝试新 ID、旧资产不覆盖 |
| Q01 | 输出拒绝/警告/未评估/不完整/错误 | 各分支禁止启用，可复测；第二次试听失败撤销旧试听确认 |
| Q02 | 取消输出检查 | 旧证据失效，迟到通过报告不解锁，重新检查后才继续 |
| A01 | 启用拒绝/成功 ACK 状态不符 | 二者均不能报成功，保留候选，重试目标状态一致才启用 |
| A02 | 主界面直接选择克隆音色 | 进入检查页，不直接发 set_voice，静音准备完成前不能试听 |
| X01 | 删除取消/失败/重试 | Escape 仅关闭子框；失败留框；重试成功；只有一次确认 |
| X02 | 删除当前声音 | 默认切换失败不 DELETE；默认成功而 DELETE 失败保留资产；允许重试 |
| X03 | 删除当前正在检查的候选 | 清除失效候选并回到可编辑设计，不保留悬空启用入口 |
| C01 | 麦克风拒绝后重试 | native MediaRecorder 合成音源录制、准确文本、固定 ID/幂等键/原始字节 |
| C02 | 等待麦克风权限时取消 | 晚到轨道立即关闭，工坊可重新录音，不出现后台采集 |
| C03 | 参考预检拒绝/未评估/异常 | 不发送注册，修正文本后可继续，无假通过 |
| C04 | 录音注册已保存但回包丢失 | 同 ID、音频 hash、幂等键和正文重试，档案库只一个逻辑资产 |
| C05 | 预检前后不同取消点 | 注册前取消不 POST；已提交取消允许晚到保存并核对找回 |
| C06 | 取消正在录制/关闭未提交录音 | 轨道停止，丢弃录音后可重录，关闭草稿要确认 |
| M01 | 助手静音被拒绝 | 录音按钮不解锁，允许静音准备重试 |
| M02 | 静音尚未确认就关闭 | 正确命令顺序 mute→await→unmute，不接受晚到 mute 留住麦克风 |
| M03 | 静音 ACK 与状态不符 | 不访问麦克风，仍可重试并等到正确状态 |
| V01 | 旧版上游无新接口 | 明确升级提示，不调用旧 metadata-only 创建接口降级 |
| V02 | 低档模型无创建能力 | 隐藏/禁用新建入口，保留档案库与解释 |
| V03 | 刷新失败/降档/恢复 | 失败保留列表，能力更新，手写描述不因暂时隐藏而丢失 |
| U01 | 明暗主题/390px/键盘 | 无横向溢出，模态焦点正确，关闭后返回触发按钮 |
| U02 | 模态内全局快捷键 | M、搜索、帮助、切换模式均不改变外层会话 |
| U03 | 手写描述未提交就关闭 | 默认继续编辑，保留修改；明确确认后才丢弃本地草稿 |

额外单元回归包含：录音 30 秒自动停止、空音频/recorder error、异步提词不污染录制文字、
播放资源释放、恢复租约合并/重连、畸形质量报告、trace ID 提取与代理幂等键边界。

## 可复跑方式

普通门禁：`cd ui && npm ci && npm test -- --run && npm run build`；Python 沿用项目的
Ruff、mypy、pytest 与原覆盖率门禁。完整数据库测试只使用独立测试 PostgreSQL，不能填用户库。

浏览器检查是可选开发依赖，不加入生产依赖。准备 Python 3.12 项目测试环境和前端锁定依赖后：

```sh
uv pip install --python .venv/bin/python 'playwright==1.57.0'
.venv/bin/python -m playwright install --with-deps chromium
.venv/bin/python scripts/voice_studio_e2e_server.py > /tmp/sona-ux-server.log 2>&1 &
SERVER_PID=$!
trap 'kill "$SERVER_PID" 2>/dev/null || true' EXIT
.venv/bin/python scripts/voice_studio_e2e.py --output /tmp/sona-voice-ux
```

脚本仅允许 loopback 目标，夹具端口 19830/19831，不启动模型、不连接用户数据库。已有受管
浏览器可通过 `--chromium /path/to/chromium` 指定；不得为测试禁用组织浏览器策略。
`--case C04` 可复跑单组。每组重新建立浏览器页和测试状态；HTTP/WS 清理完成后再结束。
CI 自动运行同一脚本，并上传 `results.json`、截图与本地夹具日志（保留 7 天）。

## 目标机剩余验收

- Safari/WebKit 的真实容器解码、权限弹窗、真实设备拔出、采集格式和系统省电/后台行为。
- 与依赖的 SpeechRail PR #46 真实联调，生成与克隆两条链的完整输入/输出证据。
- 真实 18 段检查的耗时、取消清理、模型换入/换出及峰值内存。
- 真人录音降噪前后、跨文本身份、自然度与等响度盲听。音频夹具通过不能支持这些结论。
- 其他客户端并发改音色、跨刷新/跨进程幂等与持久化版本历史仍需独立契约演进；本次
  客户端恢复不宣称提供全局事务或持久 exactly-once。
